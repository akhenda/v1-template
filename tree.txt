Please analyze the following structure of my monorepo project. It builds on top of https://next-forge.com template.

From the repo organization, you will notice that I value a lot code organization, clean architecture and separation of concerns. Please help me improve it. Also comment and critique it if necessary. Ask for more information if you need more information and give me terminal commands to extract the information for you e.g. `tree -I 'node_modules'`.

I am toying with the idea of moving the package named `convex` from `packages` to `apps`. What do you think? My reasoning is that since it is a deployable entity, it qualifies as an `app` instead of a `package`.
